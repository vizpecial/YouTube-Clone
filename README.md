# YouTube Clone

A simple YouTube-inspired UI clone built to practice front-end development and recreating real-world product layouts. This project focuses on understanding how a video platform structures its interface, organizes content, and handles responsive design.

## Features

- YouTube-like home page with navbar, sidebar, and video grid
- Video cards with thumbnail, title, channel name, and views
- Clean, minimal, and familiar UI
- Responsive layout for different screen sizes (desktop-first)

## Tech Stack

- HTML5
- CSS3

## Learning Objectives

- Recreate a real product UI using only HTML and CSS
- Practice layout techniques using Flexbox and basic responsive design
- Improve consistency in spacing, colors, and typography
- Structure a small front-end project in a clean, readable way
